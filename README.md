# مشروع Flexbox

مشروع توضيحي لاستخدام CSS Flexbox في تصميم واجهات ويب مرنة ومتجاوبة.

## الملفات

- `index.html` - هيكل الصفحة الأساسي
- `style.css` - أنماط CSS مع استخدام Flexbox
- `script.js` - أي تفاعلات JavaScript (إن وجدت)

## مفاهيم Flexbox المستخدمة

- `display: flex` - تفعيل تخطيط Flexbox
- `flex-direction` - اتجاه المحور الرئيسي (row/column)
- `justify-content` - توزيع العناصر على المحور الرئيسي
- `align-items` - محاذاة العناصر على المحور الفرعي
- `flex-wrap` - السماح للعناصر بالانتقال لأسطر جديدة
- `gap` - المسافات بين العناصر
- `flex-grow` / `flex-shrink` / `flex-basis` - التحكم في حجم العناصر

## كيفية التشغيل

افتح ملف `index.html` في المتصفح مباشرة.

## المتطلبات

- متصفح حديث يدعم CSS Flexbox (جميع المتصفحات الحديثة)
